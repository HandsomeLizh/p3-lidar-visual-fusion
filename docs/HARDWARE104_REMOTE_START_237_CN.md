# 在 237 上启动 104 建图并查看地图

104（192.168.100.104）连接真实传感器并运行建图；237（192.168.100.237）负责操作和显示。两台开机并连接到可互通的局域网。237 的显示环境已经配置好。

## 推荐：按顺序双击两个桌面图标

1. 在 237 桌面双击“01 启动104传感器采集”。它只启动/复用双目、LiDAR、IMU 及相机触发，向 ROS 发布数据，不自动录 bag 或保存原始图片。
2. 出现 `yanfa@192.168.100.104's password:` 时，输入 **104 的 SSH 密码**并回车。输入过程中不显示字符，这是正常的；密码不会写入脚本。
3. 采集启动成功后，双击“02 启动104建图并显示”。它通过 SSH 启动/复用 104 建图，然后在 237 打开标题含“104 车机”的显示窗口。首次模型加载需要等待一会儿。
4. 保持启动终端打开。窗口中显示双目累积点云、高程图、轨迹和双目图像。

如果桌面提示不允许启动，右键图标选择“允许启动”；也可以直接使用下面的终端命令。

## 终端启动（与图标相同）

在 **237 的桌面终端**执行：

```bash
cd /home/yanfa/P3/viewer104
./start_104_capture.sh       # 终端 A：只启动传感器采集
# 采集成功后，可按回车关闭终端 A，再开终端 B：
./start_104_and_view.sh      # 终端 B：只启动/复用建图，并打开显示
```

两个入口都通过 SSH 操作 104，无需先手动登录。采集和建图入口不启动底盘控制或 P4 控制器；控制程序继续单独操作。

- 104 建图已在运行：直接复用当前地图，不重新创建原点。
- 104 建图未运行：检查已存在的传感器数据，清理本工程遗留窗口，启动新版建图并创建新地图。若采集未就绪，提示先运行采集入口，不自动启动采集。
- 237 显示窗口已在运行：提示切回现有窗口。
- 当前地图仅来自双目三维点；定位仍使用视觉、LiDAR 和真实 IMU。双目点云是稀疏的，未观测的格子保持未知。

**新建图运行会改变地图原点，P4 使用前需要重新对齐。** 显示域固定为 59；使用专用目录 `viewer104`，与 237 自己的工程区分开。

## 已经在建图，只开显示

```bash
cd /home/yanfa/P3/viewer104
./start.sh
```

## 停止

关闭显示窗口、在其终端按 Ctrl+C，或执行：

```bash
/home/yanfa/P3/viewer104/stop.sh
```

这里只停止 237 的显示，104 继续建图。

需要停止 **104 建图**时，在 237 终端执行：

```bash
ssh yanfa@192.168.100.104
cd /home/yanfa/P3/lidar_visual_fusion
./stop.sh
exit
```

此操作停止这套建图，不自动关闭传感器驱动。

## 查看状态与常见问题

```bash
# 104 状态：只检查，不启停
/home/yanfa/P3/viewer104/start_104_and_view.sh --check

# 237 显示状态
/home/yanfa/P3/viewer104/status.sh
```

- SSH 超时：确认 104 开机、两台网络互通，地址仍为 `192.168.100.104`。
- 密码错误：使用 104 的 SSH 登录密码，可能与远程桌面密码不同。
- 104 已启动但没图：等待模型加载；查看显示日志 `/home/yanfa/P3/viewer104/results/`，以及 104 运行目录的 `pipeline.log`、`map_statistics.json`。
- 当前显示网络配置使用 237 的 `wlP1p1s0` 网卡。若改用其他网卡，需更新 `viewer104/config/cyclonedds.xml`。
- SSH 主机密钥发生变化时脚本会停止连接；先核实 104 是否重装，再更新 `viewer104/config/ssh_known_hosts104`。

启动入口不会自动设置目标或发出车辆移动命令。P4 启动并对齐后，其规划路径才会显示。
