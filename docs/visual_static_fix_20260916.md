# 纯视觉静止漂移与原位置接口恢复

## 现场原因

本次纯视觉入口漏接原融合链的静止检测。另有两个累积因素：双目 DLT 三角化同时拟合左右像素，右图纵向误差使点偏离左图实际视线；PnP 却继续拟合原左图像素，因此相同图片也可算出小转动。按时间每帧更换参考，又累加了这种偏差。

`visual_only_live_20260916_213835/black_cell_audit` 的观测和对照：

- 在线图有 10,517 个黑格，其中 9,680 个主要由相邻格台阶差触发。
- 同一帧 LiDAR＋双目点云各重复 10 次：固定位置为 78 个黑格；换成已记录的漂移位姿后为 10,536 个黑格。此对照未修改障碍阈值。
- 同一对真实图像重复 40 次：旧版累计约 4.96 cm 位移、0.322° 转角；修复后未出现该累积误差。重复图像实验不是行驶精度测试。

## 修复

1. 双目点保留三角化深度，视线与左图观测对齐，之后重新检查双目重投影误差。
2. 参考帧按有效运动更新，时间到期不再单独触发更新。参考是否过期按最近成功匹配时间判断。
3. 纯视觉入口启用双目光流和视觉运动量的静止确认。连续确认后约束位姿；运动、图像不可靠或输入中断时解除。静止判断不使用 LiDAR、IMU 或仿真真值；原融合入口默认仍要求图像＋点云证据。
4. 恢复域 57 的位置与轨迹兼容话题，位姿为 `odom` / `base_link`，TF 为 `map → odom → base_link`。

原错误地图保存在旧结果目录，新运行从新原点重新建图。

## 验证及限制

- 编译通过；27 项几何、静止、慢速移动、图像失效和参考恢复回归通过。
- 新运行 `visual_only_live_20260916_215943`：50 秒在线静止观察，输出位置变化范围约 0.265 mm，22 次全局地图消息的黑格数均为 94。
- `/Car/T3/localization/odometry`、`/T3/semantic/current_pose`、`/odometry/filtered` 各收到 29 条相同时间戳、相同内容的位姿；坐标系和 TF 符合原接口。
- 这是静止稳定性验证，尚不是行驶 ATE。输入偶有延迟，超时帧仍被拒绝，静止确认也会重新开始；未放宽过期数据限制。
