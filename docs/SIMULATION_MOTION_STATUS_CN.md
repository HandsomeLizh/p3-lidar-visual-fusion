# 仿真速度＋角速度：坐标与可用性最终说明

本补充采用用户最新说明：**输入是仿真的线速度＋角速度，原始轴 X 向后、Y 向下、Z 向左；不是实车加速度计＋陀螺仪。**

## 可用性结论

**这类输入可以做速度辅助，也可以积分成 SE(3) 位姿增量；没有加速度不会阻止这两种用途。** 缺少加速度只意味着不能直接按完整六轴惯导模型做 IMU 预积分。

机体线速度 v 和角速度 ω 已知时，传播关系是 `位置变化率=当前旋转×v`、`旋转变化率=当前旋转×[ω]×`。它需要明确坐标、单位和采样时间；加速度不是必需输入。应从定位器当前局部状态开始传播，不需要注入 UE 绝对位置或姿态。

**当前暂不直接启用的原因是实际输入与位姿变化的残差及时间语义还没闭合，不是因为它缺少加速度。** 仿真运动反馈应保持独立速度接口；未来实车标准 sensor_msgs/Imu 接口继续保留。

## 换轴数学已核对：现有 C 正是用户约定

原始线速度到 ROS FLU（前、左、上）：

```text
B = [[-1, 0, 0],
     [ 0, 0, 1],
     [ 0,-1, 0]],   det(B)=-1

v_FLU = B v_raw = (-vx_raw, vz_raw, -vy_raw)
```

如果原始角速度遵循对应的轴向量正转约定，则：

```text
w_FLU = det(B) B w_raw = (wx_raw, -wz_raw, wy_raw)
```

旧 P4 接收器已经做了：

```text
v_decoded = D_v v_raw,  D_v = diag(1,-1,1)
w_decoded = D_w w_raw,  D_w = diag(-1,1,-1)
```

因为两个 D 都等于自身逆矩阵，叠加后的换轴分别为：

```text
B D_v = det(B) B D_w = C

C = [[-1,0,0],
     [ 0,0,1],
     [ 0,1,0]],   det(C)=+1
```

所以，对**已被旧驱动解码的 /car/telemetry 或 /car/odom**，线速度与角速度都乘同一个 C 是正确的。本次诊断已经这样计算。**不需要再额外翻一次 Y；原始线速和原始角速不能不加区分地使用同一个 B。**

用户声明确定了原始轴名称；角速度是否严格采用上述轴向量正转定义，仍需发送端实现或实际转向数据核验。本轮 yaw 数据支持该轴/符号，但未充分验证 roll、pitch 两轴。

注意：直接读 metadata 原始字段时，应先确认它是否与车辆协议同一套原始数据。若确认，才对原始线速用 B、原始角速用 det(B)B；不能把仅适用于旧解码结果的 C 再套到原始 metadata。

## 当前量化证据与剩余误差

### 最新原地旋转段（2026-09-17 20:30:20 起约 30 秒）

603 条遥测，约 20.05 Hz；完整 payload 相邻重复率 4.64%。净位移 0.03282 m，没有足够平移激励验证线速度。

14 个参考转角超过 1° 的一秒窗口，在用户轴约定对应的 C 下：

- 解码 wy 对参考机体 yaw 相关系数 0.9834，符号一致 14/14。
- 按 deg/s 转为 rad/s 后，一秒三维姿态误差中位 0.790°。
- 直接把数值当 rad/s，一秒误差中位 80.28°。
- 全段参考 yaw 变化 61.916°，wy 按 deg/s 积分 70.922°，差约 9.006°。

因此，车辆遥测的 **Y 轴作为 yaw 主分量、角速数值更像 deg/s** 已获较强旋转段支持；但单位倍率与源时间尚未完整闭合，不能从相关系数直接宣布标定完成。

### 先前平移段（20:02:27 起约 12 秒）

同一个 C 下，9 个运动窗口的线速度方向误差中位 49.085°；反馈速度/位置差分速度比中位 2.748，线速残差中位 0.21201 m/s。

这说明实际数据仍不符合“已确认单位和时间下的该机体速度”这一完整假设。数学换轴本身已对；不能靠再翻一个 Y 或按单段拟合比例解决。发送端表达坐标、不同序列化路线、单位、仿真时钟与接收时钟关系仍需闭合。

## 最小可用条件

1. **字段绑定和换轴：** 确认当前入口是原始 metadata 还是旧驱动解码消息，按上述对应矩阵；确认角速度正转定义。
2. **单位：** 线速明确为 m/s；角速明确度/秒还是 rad/s，并且仅转换一次。车辆协议旋转段证据不能直接当作 metadata 单位声明。
3. **时间：** 用与速度定义一致的源采样时刻；如果速度按仿真时间定义，不能未经核对就用接收墙钟积分。metadata 有 batch timestamp，但每个角速与该时刻的绑定、elapsed_seconds 语义仍未确认；车辆 21 float 协议只有接收时间。
4. **误差与门控：** 通过以上条件后，可将 v、ω 放入独立 TwistWithCovarianceStamped 辅助，或做短时 SE(3) 传播，保留新鲜度、异常值、协方差和断流回退。尚未闭合的方向/尺度残差不能隐藏在小协方差里。

当前 metadata 历史原件有 velocity、angular_velocity、timestamp，没有 acceleration；因此应按仿真运动反馈评估，而非完整实车 IMU。无需伪造加速度，也无需更改实车接口。

本次没有启用辅助、修改运行配置、控制车辆或增加长期采样。原始数据和量化结果仍在同目录的 metadata_field_audit、telemetry_consistency_30s 与 gyro_yaw_crosscheck JSON。换轴数值验证见 coordinate_transform_verification_20260917.json。
