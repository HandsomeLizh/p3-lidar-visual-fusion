# 仿真视觉偏好与地面误障碍修复

2026-09-16 晚间修正。`config/simulation_live.yaml`：

```yaml
pose_source_preference: visual
visual_motion_information_scale: 1.25
```

视觉偏好通过运动增量加权实现：合格视觉的速度协方差除以 1.25，即观测信息权重提高 25%，质量检查不放宽。这是工程权重，不是精度提升保证。两路正常时保留融合滤波的 LiDAR 约束。省略偏好项或设为 `balanced` 时，保留原有不确定性比较规则；信息倍率省略时为 1。

## 本轮问题与原因

前一版在视觉质量检查通过后，直接用连续视觉的全部六维位姿替代融合结果。在线记录显示，视觉仍能匹配，却持续积累高度和倾角偏差；同时间的 LiDAR 高度稳定。平地被叠成多个高度，历史高度范围参与障碍判断，导致右侧出现随扫描位置扩展的黑块。

旧会话 `live_mapping_20260916_191621_218261` 的一次现场快照中，车周围 2～5 米有 1651 个已观测栅格，其中 1645 个被标为障碍，主要由历史高度范围触发；原始点云的近处地面很平。不能把这次问题仅归因于照明，也不能用隐藏黑色或提高障碍阈值代替融合修复。

## 运行逻辑

1. 先检查曝光、纹理、双目几何、运动一致性、时间戳、轨迹对齐和协方差。优先级不能覆盖这些检查。
2. LiDAR 和融合结果有效时，从融合滤波发布正式位姿和主 TF；视觉通过相对运动观测参与，不绕过高度、倾角等 LiDAR 约束。
3. LiDAR 失效或滤波结果不合格、过时时，可由已对齐且合格的连续视觉接续。视觉失效或过时则使用合格 LiDAR／EKF。恢复仍需连续帧确认及同时间戳参考，滤波跳变不会因协方差较小而获准输出。
4. 两路都不合格时停止可信定位。切换仍受原有位置、转角和同时间戳累计修正限制，差异过大时不会强行接上。

LiDAR 继续提供点云、高程建图、运动交叉检查、定位后备和子图恢复。地图和 RViz 使用同一个正式位姿。当前仍没有纯视觉深度建图后备。

查看 `/fusion/status` 中的 `pose_source_preference`、`visual_motion_information_scale`、`output_source`、`localization_valid` 与 `visual_continuity`。`output_source: ekf` 表示正式输出来自融合滤波，不代表视觉关闭；同时检查 `vision_enabled` 和 `visual_motion_constraints`。

## 验证

`tests/test_visual_preference_ros.py` 在隔离域 80 中使用实际融合节点、实际高程地图实现和合成前端消息，检查：

- 连续 140 帧视觉带缓慢高度、倾角偏差时，可靠的融合约束仍生效。复现夹具中，原先无约束视觉使平地区域全部误标；修正后该区域误标为零，4 个真实障碍格仍保留。
- 黑屏、完全过曝和视觉过时回退；LiDAR 失效或滤波发散时合格视觉仍接续。
- 视觉突跳仍拒绝；两路失效停发；位姿和 TF 一致。
- 原有 150 帧 LiDAR 连续失效回归通过，150 帧均由合格视觉连续输出；新视觉原点仍不能伪接旧地图，子图全局不确定性下限保留。

六个包编译通过，运行代码与构建清单一致。按用户要求保存旧图并结束旧导航后，启动 `live_mapping_20260916_194043_222725`，P4 已重新对齐，未重发旧目标。新光照下启动检查：视觉与 LiDAR 都有效，正式输出来自融合；车周围 2～5 米的 1570 个已观测格中黑色为 0，高度范围的 95 分位约 1.5 毫米，位姿与 TF 等十项接口检查全部通过。
