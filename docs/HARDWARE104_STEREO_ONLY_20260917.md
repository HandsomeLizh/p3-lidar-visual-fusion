# 104：双目几何建图，视觉/LiDAR/IMU 融合定位

## 分工

- 定位代码及其参数保持原样。地图使用 `/T3/semantic/current_pose` 正式融合位姿。
- `mapping_source: stereo` 时，建图端只订阅 `/fusion/stereo_points`，不订阅雷达或 ToF 点，也会拒绝通过其他入口送来的测距点。
- 通过双目、时序匹配及位姿质量检查的三维点，转换到地图坐标后逐帧累积；使用已有磁盘体素存储及有限预览，不另加深度网络。
- 三维地图 `/T3/mapping/stereo_map` 保留真实三维观测，不把栅格中心或拟合地面点伪装成双目点。此模式不发布 `/T3/mapping/lidar_map`。
- 局部/全局高程话题保持不变，全部来自双目观测，地面参考也由双目点拟合。未知格保留为 NaN。三维云可保留高处表面，高程只融合符合近地表条件、连续确认过的观测。
- 视觉不合格、位姿质量不合格时暂停入图；LiDAR 仍可维持定位，但不会用雷达点补地图。

配置仍是每秒最多 2 帧、每帧最多 512 个双目点；双目属于稀疏特征点云。磁盘体素 0.12 m、预览体素 0.25 m、预览最多 15 万点。全局预览有上限，完整体素图保存在运行目录中。自车范围过滤继续生效。
