# 长段融合改进依据

冻结基线：`results/long_voxelmap_80m_20260915`。同一组 174 帧，原始 VoxelMap ATE 0.04058 米；最终融合 ATE 14.273 米。门控拒绝了全部 LiDAR，视觉又存在过期与恢复中断。先解决信息丢失与坐标连续性，再评估融合收益。

## 实施次序

1. **恢复坐标关系的连续性。** 区分视觉前端真正重置坐标系、短时质量拒绝、消息传输过期三类事件。短时拒绝不能反复把同一个视觉坐标系重新绑定到旧位姿；真实重置要用独立且可信的运动约束衔接，若无法恢复中断位移，应明确标记缺口和不确定性，不能悄悄把缺口压缩为零。
2. **检查退化量的定义与尺度。** 当前未加权雅可比的最小/最大特征值比将平移和转角混合，在点的距离尺度下可能过度保守。现有“几何弱就六维一起加 1000 方差”的方法会扔掉仍然可靠的方向。应结合测量噪声、归一化后的可观测方向、残差、有效匹配空间分布和预测一致性评估。
3. **按方向保留有效约束。** 地面通常提供高度及部分姿态约束；立面、坡面和不同法向平面提供额外运动约束。分别处理可靠方向和弱方向，不用单一整体分数直接关掉整路 LiDAR。方向投影、残差和协方差必须在同一坐标系中表达，不能只改对角线充当完整实现。
4. **避免重复计算信息。** LiDAR、视觉若共用 IMU预测或同一融合位姿作为先验，误差存在相关性；不能再当作独立观测简单相乘。先采用清晰的主观测/辅助约束策略，记录每个输出究竟使用了哪些新测量，再考虑更紧密的融合。
5. **独立验证。** 固定当前 short bag 和当前长段作为回归案例，另选未调参的轨迹验证。比较纯 LiDAR、纯视觉、修改前融合、修改后融合；加入过曝、局部眩光、低照、黑屏、重复纹理、IMU 缺失/断流场景。共同报告 ATE / 同段参考路程、输出覆盖、最长缺口、处理延迟和峰值内存，不能只展示最好的一项。

## 地图衔接

P3 最新高程方差融合已经把估计置信度和地形粗糙度分开，但本项目地图仍是冻结的旧实现。后续接入还需要把位姿协方差传到高程测量、扩展磁盘瓦片持久字段和内存预算，并对地图突变、台阶、缓存换入换出做验证。定位误差应先修复，否则更复杂的高度滤波无法纠正错误位姿造成的地图错位。

以上是依据已观察故障的实施计划，尚未代表方向级融合或新地图不确定性已经实现。
