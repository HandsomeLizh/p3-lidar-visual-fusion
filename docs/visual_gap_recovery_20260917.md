# 视觉延迟后的 LiDAR 恢复修复

更新：2026-09-17。项目 `/home/yanfa/P3/lidar_visual_fusion`。本轮不接入 IMU，不改变 P4 或车辆控制。

## 问题与修改

旧流程以最后成功 LiDAR 帧为起点取独立视觉增量，却把增量间隔硬限制为 6 秒。现场视觉恢复时已经间隔约 6.87 秒，LiDAR 因而继续拒绝；失败又不能推进起点，超过 20 秒后普通视觉队列还会淘汰旧起点。这会造成视觉恢复后 LiDAR 仍长期报 `weak_geometry_needs_motion_reference`。

新版仍以最后可信 LiDAR 帧为基准，但单独保留与它同时间的独立视觉样本。连续有效的视觉结果维护恢复关系，不再把“距上次成功 LiDAR 的总时长”直接作为 6 秒禁区。普通队列仍限制为 64 个样本或 20 秒，另保留一个可信起点及一个最近有效样本。

恢复条件仍包括：

- 同一视觉 epoch、同一连续段；坐标重置或不合理视觉跳变会断开恢复关系。
- 有效视觉端点的间隔遵守前端恢复范围。当前实时配置与既有关键帧恢复一致，为最多 120 秒；这不是逐帧等待时间，LiDAR 等待仍最多 1 秒。
- 逐段运动受现有速度、角速度、步长和角度限制约束，LiDAR 速度检查仍为 0.3 m/s。
- 根据视觉端点方差、路径长度、时间和外参杆臂检查恢复增量的不确定性。默认上限为位置 0.5 m²、旋转 0.1 rad²。这是工程上的保守检查，不是经过实车标定的误差置信保证。
- 失效帧不写正式配准地图；原来的弱方向协方差处理、正式定位方差门槛和 `output_discontinuity` 保留。

长时间没有可信视觉、视觉重置或不确定性超限时，仍可能无法自动恢复。本修复解决恢复条件互相卡住的问题，不承诺消除所有定位漂移，也不是完整回环。

## 输入实时性与诊断

图像订阅深度从 1 改为 2；左右同步缓存和只保留最新一对的处理队列仍有界，不积压旧图像。新增最多 64 条轻量入口时间记录，与已有指标一起写出，不在订阅回调里写文件。传感器原始时间戳不变。

- `learned_metrics.jsonl`：`message_timing`、`ingress_events`，包括左右回调、处理开始、发布前后时间和回调到处理的等待时间。
- `lidar_metrics.jsonl`：`independent_reference_reason`、`independent_anchor_retained`、参考时间、累计路径和恢复方差。
- `fusion_status.json`：`visual_candidate_quality` 给出视觉接续候选拒绝原因、实际方差与上限；`visual_continuity.estimate_quality` 给出参考间隔、路径及估计方差。

已有日志能说明视觉计算之外发生了额外等待，但还不能独立区分 DDS 传递和进程调度。新增记录用于后续在线定位原因；加深一格订阅队列不代表已经消除全部延迟。

## 验证

使用同一真实 ROS 测试程序比较修改前、后的 VoxelMap 二进制；测试域 88，仅本机通信，输入为可控合成点云和视觉位姿，不连接车辆。

| 场景 | 旧版 | 新版 |
|---|---|---|
| 正常顺序、视觉晚到、两帧重叠 | 通过 | 通过 |
| 持续过载、突发输入 | 保留最新帧、有界丢弃 | 保留最新帧、有界丢弃 |
| 缺失或无效视觉后恢复 | 拒绝坏帧，正常帧可恢复 | 同左，失效帧不改位姿与地图 |
| 距成功 LiDAR 7.2 秒后视觉恢复 | 拒绝，无法恢复 | 成功恢复，期间失效帧未入图 |
| 连续视觉运行，36 秒后再来 LiDAR | 旧参考被缓存淘汰，拒绝 | 使用单独保留的可信起点恢复 |

共 8 组 ROS 场景通过。7.2 秒和 36 秒为测试的传感器时间跨度。它们验证恢复和队列行为，不代表实车 ATE。

另外验证了 C++ 参考过期、同 epoch 跳变、新 epoch、无效起点重复发送、累计不确定性超限、迟到起点等情况；Python 视觉关键帧、连续性、图像入口记录及输出跳变回归通过。实际 ROS Guard 测试确认视觉恢复可接续、坏深度不输出、过期参考需重新锚定，以及位姿和 TF 同时拒绝跳变。5 项启动器进程归属测试通过；现有 P4 手动控制窗口也能被复用。安装后核验源码、实际 Python 运行路径和二进制指纹一致。

证据位于 `results/visual_gap_recovery_20260917/`：`baseline_ros/report.json`、`fixed_ros/report.json`、编译及测试日志。结果目录不提交 Git；测试程序和修复代码随仓库保存。尚未进行本版车辆运动精度验收。
