# 当前实时模式：融合定位，双目点云建图

## 启动和数据流

已有 UE、capture 和控制时，在远程执行：

```bash
cd /home/yanfa/P3/lidar_visual_fusion
./start_live.sh
```

这个入口只启动本项目的定位、地图、传感器转接和 P3 组合窗口，不启动 P4、不发布行驶命令。

- 定位：XFeat/LighterGlue 双目运动＋VoxelMap LiDAR 约束；两路都可用时输出经过质量检查的融合位姿，异常时由仍然合格的一路接续。
- 建图：只有双目三角化点云，经对应时刻车体位姿变换后逐帧累积。LiDAR 仅用于定位及其内部配准地图。
- 地图：局部 32×32 米、0.2 米/格；局部和全局发布周期均为 2 秒。只有高度、方差、观测次数三层，P4 决定通行性。
- 当前 LiDAR 参数：根体素 1 米，降采样 0.1 米，迭代上限 30。保留标准 IMU 接口，当前没有启用经标定的 IMU 融合。下方历史体素对比使用当时的 0.2 米降采样。

`config/simulation_live.yaml`：

```yaml
mapping_sources: [stereo]
stereo_mapping_topic: /fusion/stereo_points
publish_terrain_classification: false
```

启动时建立新的地图目录。历史 LiDAR/RoMa 地图保留在原结果目录，不加载进本次双目地图。

## 发布什么

| 话题 | 内容 |
|---|---|
| `/Car/T3/localization/odometry` | 合格车体定位，来自融合或可用单路接续 |
| `/fusion/stereo_points` | 当前双目帧测得的点，`base_link` 坐标系 |
| `/T3/mapping/lidar_map` | 仅双目累计点云预览，`map` 坐标系；沿用历史接口名 |
| `/Car/T3/mapping/grid_map` | 车周围局部高程，`odom` 坐标系 |
| `/Car/T3/mapping/global_grid_map` | 当前累计全局高程，`map` 坐标系 |

查看 `results/latest/map_statistics.json`：应为 `mapping_sources=["stereo"]`，`lidar_scans=0`，`stereo_scans` 随有效观测增长。界面也显示“仅双目点云建图”。

## 几何与异常处理

复用已有轻量特征匹配，不新增第二套大模型。三角化检查视差方向、极线误差、重投影误差、空间覆盖及深度不确定性；近场筛选后才发布。按当前 640 像素图像、约 25 cm 基线和默认误差模型，最大有效深度约 4.9 米，不等于 LiDAR 的观察范围。

视觉位姿跟踪与双目深度分别判定：时间匹配失败时，当前双目深度若仍合格，可配合同时间戳的 LiDAR/融合位姿建图。没有合格位姿、双目深度失败、坐标系错误或过期数据均不入图。双目不可用时保留地图，不用 LiDAR 填补新区域。

当前是稀疏双目点云，未观察到的格子保持未知，不插值制造地面。重复观测进行不确定性加权；连续高程冲突暂停入图。暂未实现双目射线动态清除。相机实际安装外参仍需实测确认，软件几何测试不能替代标定。

## 已完成的验证

- 8 项双目几何回归：尺度、变换方向、错误匹配剔除、重复图像、外参仅应用一次，以及“时间跟踪失败仍保留当前合格深度，下一帧深度失败不会复用旧点”。
- 隔离 ROS 测试：平移和转弯后双目点仍落在正确世界位置；LiDAR 障碍不改变仅双目地图；错误坐标和缺少对应位姿的点被拒绝。原混合点云模式也通过回归。
- 在线 35 秒只读检查通过：双目入图 112→136 帧，LiDAR 入图始终为 0，地图节点没有订阅 `/fusion/lidar`。两路定位各收到 24 帧，35 次健康采样均为有效融合定位；局部高程收到 18 条，全局收到 19 条（含锁存消息）。这段是静止检查，不是移动精度验收。
- 10 组同时间戳的近场平面比较：1381 个有效对照点，双目点到 LiDAR 局部平面的有符号高度差中位数 −1.78 cm，绝对差 P95 4.90 cm。LiDAR 只用于只读核验，没有把对照点或拟合修正写入双目地图，也没有修改外参。该局部结果不能证明完整外参已标定。
- 体素对比使用相同的 68 帧历史输入，52 个运动时刻参与评分，参考路程约 14.10 米；固定尺度刚体对齐，没有拟合时间差。结果是这段记录的诊断，不代表所有场景。

## 先前远处黑圈的记录

切换前的 RoMa 定位＋LiDAR 建图快照显示：按 P4 原规则重算，6–9 米已知格约 40% 触发障碍，12–16 米约 93%；原始同场景单帧 LiDAR 的 6–9 米区域仍是平滑地面。说明累计高程的不连续已经存在于 P3，P4 膨胀进一步扩大了黑色区域。稀疏远场的不同时间观测叠加、位姿高度/倾角变化，以及较低观测受保护规则限制，是需要结合时间序列继续核验的因素；不能归因于“体素太大”或“P4 凭空生成障碍”。
